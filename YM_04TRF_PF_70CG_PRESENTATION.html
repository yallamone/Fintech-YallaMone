Phase 1 — Import des fichiers TRFJOUR
Chargement et analyse automatique des fichiers source

L'utilisateur glisse-dépose ou sélectionne ses fichiers TRFJOUR (tous formats acceptés, avec ou sans extension). Le système analyse automatiquement le contenu pour détecter les combinaisons CF / CG / SCOMPTE disponibles et prépare le traitement.

TRFJOUR — 180 colonnes fixes

Extensions acceptées
Tous formats, y compris sans extension

⚙️
Option — Inclure / Exclure les lignes pré-marquées "OK"
Paramètre de filtrage avant traitement

Avant de charger les fichiers, l'utilisateur peut choisir d'inclure ou d'exclure les lignes déjà validées (marquées "ok") pour produire un fichier de contrôle allégé concentré sur les écarts non encore traités.

Mode désactivé (défaut)
Lignes pré-OK exclues → fichier allégé
Mode activé
Toutes les lignes incluses → vue complète

Phase 3 — Traitement & Enrichissement des données
Parsing ligne par ligne et calcul des champs enrichis

Chaque ligne du fichier TRFJOUR (format fixe 180 colonnes) est parsée et enrichie avec des champs calculés supplémentaires. Le traitement applique les règles métier bancaires marocaines pour produire un fichier de rapprochement opérationnel.

Phase 5 — Synthèse SALAFIN (CG 23669)
Réconciliation avancée avec auto-matching et validation manuelle

Pour le compte général CG 23669 (SALAFIN), un module spécial de synthèse permet d'ajuster le SORT de chaque ligne avant la génération du fichier. Le système propose un auto-matching des paires d'écarts et signale les rapprochements exacts (NF) et les sommes proches de zéro (SS).

Règles spéciales CG 44686 / 44687
Rapprochement groupé — v3.25 & v3.26

Les lignes SS (somme proche de zéro) sont conservées avec les lignes Non-OK car elles contribuent au solde total du compte. Le rapprochement se fait par regroupement des lignes de même Date Opé et Nature.
